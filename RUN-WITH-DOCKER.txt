ETT HIRING PORTAL - RUN WITH DOCKER
===================================

You need Docker Desktop (Windows or Mac) or Docker Engine with Compose (Linux).


0. GET THE CODE (once)
----------------------
Either unzip the package you were sent, or download it from GitHub
(needs Git):

    git clone https://github.com/epictaasforce/epictalenttrust.git
    cd epictalenttrust


1. CREATE YOUR SETTINGS FILE (once)
-----------------------------------
Your settings and passwords live in a file called .env. It is never stored
on GitHub or in the zip, so that passwords don't leak. The file .env.example
is the template to copy.

Open a terminal in this folder (the one with docker-compose.yml) and run:

    Windows (PowerShell):   copy .env.example .env
    Mac or Linux:           cp .env.example .env

Open .env in a text editor (Notepad is fine) and change DATABASE_PASSWORD
to a long password of your own. Everything else can stay as it is for a
trial.

If you skip this step, Docker stops with "Set DATABASE_PASSWORD in .env".


2. START
--------
    docker compose up -d --build

The first start downloads and builds everything, which takes 5 to 15
minutes. Later starts take under a minute.

4. STOP, RESTART, START AGAIN
-----------------------------
    Stop:                   docker compose down
    Start again:            docker compose up -d
    See what went wrong:    docker compose logs backend --tail 50
    Wipe all data and
    reload the sample:      docker compose down -v
                            docker compose up -d


GETTING THE LATEST VERSION
--------------------------
If you downloaded from GitHub, get the latest changes and rebuild. Your .env
and your data are kept:
        git pull
        docker compose up -d --build

If you tried a much earlier version of the portal on this computer, wipe the
old sample data once so the new sample loads:
        docker compose down -v
        docker compose up -d --build


IF SOMETHING DOESN'T START
--------------------------
"container ett-hr-portal-db-1 is unhealthy":
    The database didn't start. Usually this is data left by an older trial
    of the portal. Remove the old data and start again (this deletes the
    sample data, which is loaded again):
        docker compose down -v
        docker compose up -d --build
    To see the reason:  docker compose logs db --tail 30

"port is already allocated":
    Something else on this computer uses port 8081 or 8025. In .env, set
    HTTP_PORT=8082 (or MAIL_UI_PORT=8026) and start again.


5. YOUR OWN CLIENT INSTEAD OF THE SAMPLE
----------------------------------------
In .env, leave SPRING_PROFILES_ACTIVE empty and fill in ETT_FIRST_COMPANY,
ETT_FIRST_ADMIN_NAME, ETT_FIRST_ADMIN_EMAIL and ETT_FIRST_ADMIN_PASSWORD.
Run "docker compose down -v" and "docker compose up -d". Then sign in as
that admin, upload the client's logo under Settings, and remove the password
from .env.

For a live installation also set ETT_SAMPLE_REPORTS=false. README.md has the
full production checklist (HTTPS, your mail provider, backups).
